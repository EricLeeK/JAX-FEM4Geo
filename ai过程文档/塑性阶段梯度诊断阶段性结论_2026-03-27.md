## 3. 已得到的关键结果

### 3.1 实验 3：单积分点 AD vs FD 一致

`exp3_single_point.py` 从 FEM 解中提取了两个代表性 `u_grad`：

1. 体积加权平均的 `u_grad`
2. `f_yield` 最大的积分点 `u_grad`

这两个代表点在当前算例中数值一致，对应结果为：

- `sigma_zz = -1.80056227e+02`
- `f_yield = 1.14540690e+02`
- `plastic = True`
- `apex = False`

梯度对比如下：

- `dL/dE`：AD = `-2.77708768e-03`，FD = `-2.77708768e-03`
- `dL/dk`：AD = ` 2.86798213e-01`，FD = ` 2.86798312e-01`

相对误差量级：

- `dL/dE`：约 `1e-10`
- `dL/dk`：约 `3e-7`

结论：**单积分点 return mapping 本身在该塑性点上没有表现出 AD/FD 不一致。**

这说明当前问题大概率不在本构局部更新公式本身。

---

### 3.2 实验 2：`params +/- eps` 下没有 active set 切换

`exp2_active_set.py` 分别检查了：

- `E - 100`、`E`、`E + 100`
- `k - 1`、`k`、`k + 1`

统计结果：

- 基准、正扰动、负扰动三组中，均为 `64 / 64` 个积分点处于 plastic
- 三组中 apex 点数均为 `0`
- 与基准相比，plastic mask 的切换点数均为 `0`
- 与基准相比，apex mask 的切换点数均为 `0`

结论：**在当前 `displacement = -0.03 mm`、当前 FD 步长下，没有观测到 active set 切换。**

这意味着规划文档中的“FD 跨了不同分支，因此不可信”这一解释，至少在当前这组参数和步长下，并没有得到支持。

---

### 3.3 实验 1：FD 对 `E` 非常稳定，对 `k` 在小步长下也稳定

`exp1_fd_sweep.py` 扫描了：

```text
[500, 200, 100, 50, 20, 10, 5, 2, 1, 0.5, 0.1]
```

#### 对 `E` 的结果

AD 给出：

- `dL/dE (AD) = -1.26035621e-05`

FD 扫描结果几乎是常数：

- `dL/dE (FD) ≈ -2.77708768e-03`

从 `eps = 500` 到 `eps = 0.1`，FD 基本没有漂移。

结论：**对 `E` 而言，FD 不是不稳定，而是非常稳定地收敛到一个与 AD 完全不同的值。**

#### 对 `k` 的结果

AD 给出：

- `dL/dk (AD) = -3.58347955e+00`

FD 在较大步长下有明显变化：

- `eps = 500` 时约 `3.53e-01`
- `eps = 200` 时约 `4.93e-02`
- `eps = 100` 时约 `-4.79e-01`
- `eps = 50` 时约 `-1.66`

但在较小步长后迅速稳定：

- `eps = 20` 时约 `2.86837733e-01`
- `eps = 10` 时约 `2.86808094e-01`
- `eps = 5` 时约 `2.86800683e-01`
- `eps = 2` 时约 `2.86798608e-01`
- `eps = 1` 时约 `2.86798312e-01`
- `eps = 0.1` 时约 `2.86798214e-01`

结论：**对 `k` 而言，大步长会混入非线性效应，但小步长 FD 明显收敛到稳定平台。**

综合起来看：

- `E` 的 FD 稳定但与 AD 强烈不符
- `k` 的 FD 在小步长时稳定，但与 AD 符号相反且量级严重不符

因此目前不能把问题简单归因于“FD 不可信”。

### 3.4 实验 4：Taylor test 显示全局 AD 梯度不是正确的一阶近似

`exp4_taylor_test.py` 使用随机方向 `delta p`，检验：

- `r0(eps) = |L(p + eps * delta p) - L(p)|`
- `r1(eps) = |L(p + eps * delta p) - L(p) - eps * grad_ad · delta p|`

理论上，如果 AD 梯度正确：

- `r0 ~ O(eps)`
- `r1 ~ O(eps^2)`

实际结果：

- `r0` 的收敛阶稳定为 `1.000`
- `r1` 的收敛阶也稳定为 `1.000`

也就是说：

- `r0` 符合一阶行为
- `r1` 没有出现二阶衰减，而是仍然只有一阶衰减

这说明：**当前 `ad_wrapper` 给出的全局梯度，在该塑性工况下不是该离散问题的正确一阶线性化。**

这是目前最强、最直接的证据。

## 4. 当前最合理的诊断判断

基于前 4 个实验，目前最合理的判断是：

### 判断 1：问题不在单点本构 return mapping

原因：实验 3 中，局部 `stress_return_dp(...)` 的 AD 和 FD 在塑性点上高度一致。

### 判断 2：问题也不像是 `params +/- eps` 导致的 active set 切换

原因：实验 2 中，没有观测到 plastic/apex active set 的切换。

### 判断 3：问题更可能出在全局 FEM 隐式微分链路

原因：

1. 实验 1 显示 FD 在小步长下是稳定的，而不是随机振荡
2. 实验 4 显示 AD 梯度未通过 Taylor test 的一阶正确性检验
3. 当前 `jax_fem/solver.py` 中 `implicit_vjp(...)` 使用的是最终 Newton 状态下的切线矩阵 `A`

因此目前最可疑的是规划文档中的 **假设 B**：

> `ad_wrapper` 的隐式微分在塑性阶段与真实离散映射不一致。

换句话说，当前最像的情况是：

- 前向求解是能收敛的
- 单点本构是可微/至少局部可校验的
- 但全局伴随或隐式微分使用的线性化对象，不等于真实离散求解器在该塑性点上的一阶映射

## 5. 尚未完成的两项实验

### 5.1 实验 5：光滑化扫描

`exp5_smoothness_sweep.py` 已实现，目的为：

- 将 `max(0, f_yield)` 替换为 `softplus(beta * f_yield) / beta`
- 扫描 `beta = [1, 5, 10, 50, 100, 500]`
- 观察 AD/FD 是否改善

它的意义是区分两种可能：

1. 如果光滑化后 AD/FD 显著改善，说明非光滑切换仍然有重要影响
2. 如果光滑化后仍不改善，则更支持“隐式微分框架本身不匹配”

### 5.2 实验 6：位移扫描

`exp6_displacement_sweep.py` 已实现，目的为：

- 扫描位移从 `-0.020` 到 `-0.035 mm`
- 统计 AD/FD 误差与 plastic 点数量随位移的变化

它的意义是确定：

- AD/FD 失配是在哪个位移附近开始出现
- 是否与塑性激活同步出现
- 是突变还是渐变

## 6. 当前阶段结论

截至本次记录，可以比较明确地写出下面这句阶段性结论：

**在 `displacement = -0.03 mm` 的塑性工况下，单积分点 Drucker-Prager return mapping 的 AD/FD 是一致的，`params +/- eps` 下也没有 active set 切换；但全局 FEM 的 AD 梯度未通过 Taylor test，且与稳定的 FD 平台严重不符，因此当前最可疑的问题来源是 `ad_wrapper / implicit_vjp` 在塑性阶段的隐式微分线性化不一致，而不是单点本构公式或 FD 本身。**
