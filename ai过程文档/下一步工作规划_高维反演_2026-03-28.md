## 2. 阶段 G：2D 平面应变基础设施

> **目标**：将当前 3D DP 模型迁移到 2D 平面应变，为后续高维反演（2D 网格比 3D 网格单元数更可控）提供基础。

### 任务 G1：2D 平面应变 DP 本构模型

**为什么需要 2D**：

- 开题报告所有算例均为 2D
- 隧道开挖是典型的 2D 平面应变问题
- 高维反演需要大量单元（如 50×50 = 2500 个单元），3D 网格计算成本过高
- JAX-FEM 已支持 2D（QUAD4、TRI3），只需迁移本构

**实现方案**：

新建 `src/models/drucker_prager_2d.py`：

```python
class DruckerPragerPlasticity2D(Problem):
    """2D 平面应变 Drucker-Prager 本构。
    
    vec=2, dim=2, 但应力/应变使用 3×3 张量表示
    （平面应变：ε_33 = 0, σ_33 ≠ 0）。
    
    E, k 通过 internal_vars[2], [3] 传参（支持逐单元异质）。
    """
```

关键设计：

| 决策 | 选择 | 理由 |
|---|---|---|
| 应力/应变张量维度 | 3×3（含 out-of-plane） | 平面应变 σ_33 ≠ 0，影响屈服判断 |
| u_grad 维度 | 2×2 | JAX-FEM 的 `sol_to_grad` 在 dim=2 时输出 2×2 |
| 应变扩展 | `ε_3D = [[ε_2D, 0], [0, 0]]` | 标准平面应变假设 |
| 返回映射 | 复用 3D 公式，只是输入应变不同 | 一致性 |

**验证**：

1. 与 3D 单元柱对比（3D 模型 z 方向约束所有节点 → 等价平面应变）
2. 弹性阶段：σ_zz = ν(σ_xx + σ_yy)（平面应变解析解）
3. AD vs FD 梯度验证（沿用 `test_diff_dp.py` 模式）

**产出文件**：

- `src/models/drucker_prager_2d.py`
- `tests/test_diff_dp_2d.py`
- `examples/run_fem_2d.py`（简单 2D 压缩验证）

## 3. 阶段 H：高维非均质参数场反演框架

> **目标**：从"2 个标量参数反演"扩展到"每个单元一个独立 E（或 k）"的高维参数场反演。
> 
> 这是开题报告的**核心创新点**——维度达数千到数万。

### 任务 H1：`set_params` 支持逐单元参数场

**当前状态**：

`set_params(params)` 接收 `params = [E_scalar, k_scalar]`，然后 `np.full((nc, nq, 1), params[0])` 广播到全场。

**修改方案**：

新建 `InversionHeterogeneousDP` 类，支持两种模式：

```python
class InversionHeterogeneousDP(Problem):
    """DP problem with per-element E field for high-dimensional inversion."""

    def set_params(self, params):
        """params: shape (num_cells,) — each element has independent E."""
        nc, nq = len(self.fe.cells), self.fe.num_quads
        # Expand from per-cell to per-quadrature-point
        E_field = np.repeat(params[:, None, None], nq, axis=1)  # (nc, nq, 1)
        self.internal_vars[2] = E_field
```

**关键设计**：

| 问题 | 方案 |
|---|---|
| 参数维度 | 每个单元 1 个 E 值，总参数 = num_cells |
| k 是否也逐单元 | 先固定 k 为常数（减小问题规模），后续可扩展 |
| `ad_wrapper` 兼容性 | 无需修改——`set_params` 被 `ad_wrapper` 在 `fwd_pred` 内调用，JAX 自动追踪 |
| 初始猜测 | 均匀场（如 E_init = 70000 全场）|
| 参数约束 | E > 0，通过参数化保证：`E = E_min + softplus(θ)` |

**验证**：

1. 均匀场反演 → 应退化为 D1 的结果
2. 双区域场（左半 E=50000，右半 E=90000）→ 能否恢复界面

### 任务 H3：高维反演 Loss 函数

**数学形式**：

```
Loss(E_field) = ||u_FEM(E_field) - u_obs||² + λ · R(E_field)
```

**实现**：

```python
def heterogeneous_loss(E_field, problem, fwd_pred, obs_data, obs_indices, 
                       regularizer=None, reg_weight=0.0):
    """
    E_field: (num_cells,) — 待反演参数
    obs_data: (num_obs_points, vec) — 观测位移
    obs_indices: (num_obs_points,) — 观测点节点索引
    """
    sol = fwd_pred(E_field)[0]
    u_pred = sol[obs_indices]
    data_misfit = np.sum((u_pred - obs_data) ** 2)
    
    reg_term = 0.0
    if regularizer is not None:
        reg_term = reg_weight * regularizer(E_field)
    
    return data_misfit + reg_term
```

## 4. 阶段 I：正则化与优化策略

> **目标**：解决高维反演的不适定性问题——无正则化时，反演结果呈"像素噪声"。

### 任务 I1：总变分正则化（TV）

**数学形式**：

```
R_TV(E) = Σ_neighbors ||E_i - E_j||
```

其中求和遍历所有相邻单元对 (i, j)。

**特性**：鼓励分块常数解（piecewise constant），适合识别**清晰界面**（层状岩体、软弱夹层）。

**实现**：

```python
def tv_regularizer(E_field, neighbor_pairs):
    """Total Variation regularization.
    
    Args:
        E_field: (num_cells,) 
        neighbor_pairs: (num_pairs, 2) — 相邻单元索引对
    """
    diffs = E_field[neighbor_pairs[:, 0]] - E_field[neighbor_pairs[:, 1]]
    # 使用 smooth L1 代替 L1 以保持可微性
    eps_tv = 1e-6
    return np.sum(np.sqrt(diffs**2 + eps_tv))
```

**邻居关系获取**：

### 任务 I2：高斯平滑正则化

**数学形式**：

```
R_smooth(E) = Σ_i ||E_i - mean(E_neighbors(i))||²
```

或等价的 Laplacian 正则化：

```
R_Lap(E) = ||L · E||²
```

其中 L 是网格 Laplacian 矩阵。

**特性**：鼓励参数场**空间平滑**，防止非物理振荡。适合**渐变型**非均质。

**实现**：

```python
def gaussian_smooth_regularizer(E_field, laplacian_matrix):
    """Laplacian smoothness regularization."""
    return np.sum((laplacian_matrix @ E_field) ** 2)
```

### 任务 I3：正则化权重自适应选择

**方案**：

| 方法 | 说明 |
|---|---|
| L-curve 方法 | 扫描 λ，绘制 (data_misfit, reg_term) 曲线，取拐点 |
| 交叉验证 | 留出部分观测点做验证集，选择验证误差最小的 λ |
| 固定比例 | λ = c · ||∇data_misfit|| / ||∇reg_term||（梯度平衡） |

**实验**：

- 在 H5 的双区域算例上，扫描 λ ∈ [1e-4, 1e-3, ..., 1e2]
- 对比 TV 和 Gaussian 正则化的效果
- 绘制 L-curve

## 10. 关键技术风险与应对

### 风险 1：2D 平面应变 DP return mapping 的 JAX-FEM 兼容性

JAX-FEM 的 `get_tensor_map()` 在 dim=2 时期望返回 2×2 应力张量，但 DP 需要 3×3（含 σ_33）。

**应对**：检查 JAX-FEM 源码中 `dim=2` 时 `tensor_map` 的输入/输出约定。可能需要在 return mapping 内部用 3×3 计算，然后截取 2×2 返回。或者使用 Voigt 记号。

### 风险 2：高维反演的内存/计算瓶颈

2500 参数 → `jax.grad` 的伴随计算需要存储整个前向计算的中间状态。

**应对**：
- JAX 的 `jax.checkpoint`（梯度检查点，用内存换计算）
- 先用 CPU 跑正确性，再迁移 GPU（课题组有 4×A100）
- 批量化：将大规模问题拆分为子域

### 风险 3：正则化权重 λ 的选择高度依赖问题

λ 过大 → 过平滑，丢失细节；λ 过小 → 像素噪声。

**应对**：
- I3 系统实验确定合理范围
- L-curve / 交叉验证自动选择
- 论文中汇报 λ 对结果的影响

### 风险 4：PSO 在高维度不可行

100 维以上 PSO 基本不收敛，实验可能无法产出有意义的对比。

**应对**：
- 低维度（2-50）跑完整对比
- 高维度只跑 AD 和有限的 FD 步骤
- 理论分析 + 外推，辅以"PSO 100 次迭代后仍未收敛"的实验证据

### 风险 5：Newton solver NaN 在大规模 2D 问题中复现

大网格 + 非均质场 → 局部单元可能进入极端应力状态。

**应对**：
- 已实现的 line search + 增量加载机制可直接复用
- 可能需要默认在所有高维反演中启用 `line_search_flag=True`
