# 塑性阶段 AD vs FD 梯度不一致：诊断规划

> 日期：2026-03-25  
> 状态：待执行  
> 目标：**查清 displacement = -0.03 mm 时 AD 与 FD 梯度不一致的根因，判断是 AD 实现有缺陷、FD 在此工况不可信、还是问题本身在该点不光滑。**

---

## 0. 问题复述

当前 `test_diff_dp.py` 中：

- **displacement = -0.01, -0.02 mm（弹性范围）**：AD 与 FD 完美一致（相对误差 < 1e-13）。  
- **displacement = -0.03 mm（进入塑性）**：  
  - `dLoss/dE`：AD ≈ -1.26e-05，FD ≈ -2.78e-03 → **相对误差 ≈ 99.5%**  
  - `dLoss/dk`：AD ≈ -3.58，FD ≈ +0.29 → **符号都反了**

Loss 函数是体积加权平均 σ_zz，材料参数 `E = 70000, k = 50`。

---

## 1. 可能的根因分析

### 假设 A：FD 在塑性分支边界不稳定

`E ± eps_E`（eps_E = 100）对应 `E ∈ [69900, 70100]`。  
屈服应力近似 `σ_y ≈ k / (1/√3 - α) ≈ 180 MPa`。  
`ε_y ≈ σ_y / E`。  
当 E 从 69900 → 70100 变化时：

- `ε_y` 从 `180/69900 ≈ 0.002575` → `180/70100 ≈ 0.002568`
- 施加应变 = 0.003（-0.03 mm / 10 mm）

两端都超过屈服应变 → **同一个塑性分支**。  
但 `k` 扰动 `k ± 1`（即 49 → 51）会显著改变 `σ_y`（172 → 184 MPa），`ε_y` 从 0.00246 → 0.00263。  
在 `ε = 0.003` 时，`k = 49` 时深入塑性、`k = 51` 时刚进塑性 → **可能在两个不同的 active set 分支**。

**如果 active set 不一致，FD 就不再是「同一个函数」的差分，数值上不可靠。**

### 假设 B：ad_wrapper 的隐式微分在塑性下不一致

`ad_wrapper` 的反向传播使用 `implicit_vjp`：

```
∂L/∂p = -λ^T · (∂c/∂p)
```

其中 `λ` 由伴随方程 `A^T λ = ∂L/∂u` 求解，`A` 是**最后一步 Newton 迭代的切线刚度矩阵**。

但 `A` 的计算基于 `problem.newton_update(sol_list)`，对应的本构切线是当前 `(sigma_old, epsilon_old)` 下的切线。如果某些积分点的屈服状态在 Newton 迭代过程中发生了切换（elastic → plastic 或反之），**最后一步的 A 只反映最终切换状态**，而不是整个 Newton 路径。

对于光滑问题（弹性），这没有影响；  
对于非光滑塑性 return mapping（含 `np.where(f_yield > 0, ...)`），**隐式函数定理在非光滑点不严格成立**。

### 假设 C：loss 函数中的 post-processing 应力与 FE 残差中的应力不完全等价

`loss_fn` 里调用 `volume_avg_sigma_zz(fe, sol, E, k)`，其中 `sigma_old = 0, epsilon_old = 0`（未更新）。  
但 FE 求解时的 `internal_vars` 同样是 `[sigma_old=0, epsilon_old=0]`（因为只做了一步加载、没有调用 `update_stress_strain`）。

**因此 loss 中的应力计算与 FE 残差中的应力计算应该是同一回事。这个假设可能不是根因，但需要实验验证。**

### 假设 D：正则化参数 `a = 0.1 * k` 不够平滑

当前 `a = 0.1 * k = 5.0`，`sqrt(J2 + a^2)` 在 `J2 ≈ 0` 附近提供了曲率，但在 `f_yield` 附近：  
`f_yield_plus = np.where(f_yield > 0, f_yield, 0.)` 仍然是**精确分段线性**的 `max(0, x)`。  
`np.where` 不是 softplus、不是光滑近似 —— 在 `f_yield = 0` 处**导数不连续**。

`jax.grad` 能对 `np.where` 求导（走其中一个分支的导数），但如果扰动让某些积分点在 `f_yield ≈ 0` 附近切换分支，**AD 和 FD 看到的"函数"就不一样了**。

## 2. 实验设计

所有实验脚本放在 `experiments/plasticity_gradient_diagnostic/` 目录下。

### 实验 1：FD 步长扫描（`exp1_fd_sweep.py`）

**目的**：判断 FD 本身是否稳定。

**方法**：  
对 `displacement = -0.03`，固定 `params = [70000, 50]`，分别对 E 和 k 扫描多组 eps：

```
eps_values = [500, 200, 100, 50, 20, 10, 5, 2, 1, 0.5, 0.1]
```

对每个 eps 计算中心差分梯度，画出 `grad_fd vs eps` 曲线。

**判断标准**：
- 如果 FD 梯度在一个区间内趋于稳定平台 → FD 可信，AD 有问题
- 如果 FD 梯度随 eps 剧烈振荡或无平台 → FD 不可信（非光滑）

### 实验 2：Active Set 分析（`exp2_active_set.py`）

**目的**：检查 `params ± eps` 时屈服状态是否发生切换。

**方法**：  
对 `displacement = -0.03`，用 E 和 k 的正负扰动分别求解，然后检查每个积分点的 `f_yield` 值：

- 正扰动解 → 统计 `f_yield > 0` 的积分点数
- 负扰动解 → 统计 `f_yield > 0` 的积分点数
- 基准解 → 同上
- 对比三者是否一致

**判断标准**：
- 如果三者 active set 完全相同 → 问题不在分支切换
- 如果有积分点在 ±eps 下切换 → FD 跨了非光滑分支边界

### 实验 3：单积分点 AD vs FD（`exp3_single_point.py`）

**目的**：**剥离 FEM 全局求解**，只测试 return mapping 本身的可微性。

**方法**：  
给定一组 `u_grad`（对应 -0.03 mm 下典型单轴压缩），直接用 `stress_return_dp(...)` 函数计算 `σ_zz`。  
对 `E` 和 `k` 分别用 `jax.grad` 求 AD 梯度、用中心差分求 FD 梯度。

**判断标准**：
- 如果单积分点 AD vs FD 一致 → 本构自身可微性 OK，问题出在 FEM 全局隐式微分
- 如果单积分点也不一致 → 本构实现有非光滑性问题

### 实验 4：Taylor Test（`exp4_taylor_test.py`）

**目的**：用比"比较两个梯度分量"更严格的方式验证 AD 梯度是否是一阶近似。

**方法**：  
定义一个随机方向 `δp`，对一系列 `ε = [1e-1, 1e-2, ..., 1e-6]` 计算：

```
r0(ε) = |L(p + ε·δp) - L(p)|                          → 应 ~ O(ε)
r1(ε) = |L(p + ε·δp) - L(p) - ε·grad_ad·δp|           → 应 ~ O(ε²)
```

如果 `r1(ε)` 确实以 O(ε²) 递减 → AD 梯度是正确的一阶近似。  
如果只以 O(ε) 递减 → AD 梯度与该离散问题不一致。

### 实验 5：正则化强度扫描（`exp5_smoothness_sweep.py`）

**目的**：测试非光滑性是否是根因。如果把屈服面做得更"圆滑"，AD/FD 是否改善。

**方法**：  
把 `f_yield_plus = np.where(f_yield > 0, f_yield, 0.)` 替换成 `softplus(β·f_yield)/β`，  
扫描 `β` 值 `[1, 5, 10, 50, 100, 500]`。

对每个 β，重新跑完整 FEM + AD + FD。

**判断标准**：
- 如果 β 较小时 AD/FD 一致，β 较大时（趋近 max(0, x)）不一致 → **非光滑 `np.where` 就是根因**
- 如果即使 β 很小也不一致 → 问题不在非光滑，更可能在隐式微分框架

### 实验 6：渐进加载位移扫描（`exp6_displacement_sweep.py`）

**目的**：找到 AD/FD 分叉的精确临界位移，对应屈服激活边界。

**方法**：  
扫描位移从 -0.020 到 -0.035（步距 0.001 mm），对每个位移计算 AD 和 FD 梯度，画出误差 vs 位移曲线。

**判断标准**：
- 误差是突变的（在某个位移处跳升） → 对应屈服激活边界
- 误差是渐变的 → 不只是边界问题

## 3. 实验执行顺序

```
实验 3（单点）        → 快速排除本构可微性问题
    ↓
实验 1（FD 步长扫描） → 判断 FD 是否可信
    ↓
实验 2（Active Set）  → 判断是否跨了分支
    ↓
实验 6（位移扫描）    → 定位临界点
    ↓
实验 4（Taylor Test）  → 严格验证 AD 是否一阶正确
    ↓
实验 5（正则化扫描）  → 如果其他实验指向非光滑，这个确认
```

**预估优先级**：  
实验 3 和实验 1 是最关键的两步；如果实验 3 证明单点可微、实验 1 证明 FD 不稳定，就基本可以下结论"FD 在非光滑分支边界处不可靠"。  
如果实验 3 也不一致，就要往本构 `np.where` 和 apex 切换上查。

## 4. 预期结论与后续路线

### 情况 A：根因是 `np.where` 非光滑 + active set 切换

**后续路线**：
1. 将 `np.where(f_yield > 0, ...)` 替换为 `softplus` 或类似光滑近似
2. 重新跑 AD vs FD，验证塑性阶段一致
3. 评估光滑化对前向精度的影响（与 constitutive driver 对比）
4. 如果可接受，更新 `src/models/drucker_prager.py` 为光滑版本

### 情况 B：根因是 `ad_wrapper` 的隐式微分假设在塑性下不满足

**后续路线**：
1. 查看是否可以用一致切线（consistent tangent）替代当前切线
2. 考虑对整个 Newton 过程做可微（例如 unrolling 或 implicit differentiation with fixed-point iteration）
3. 评估对 JAX-FEM solver.py 的改动量

### 情况 C：FD 本身不可信，AD 实际上是对的

**后续路线**：
1. Taylor test 通过即可确认 AD 正确
2. 把塑性阶段加载点纳入自动测试（用 Taylor test 代替 FD 对比）
3. 可以放心进入下一阶段（参数反演）
