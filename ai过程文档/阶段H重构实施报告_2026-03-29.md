## 0. 为什么需要重构

前一版阶段 H 使用**位移控制边界条件**（Dirichlet BC: 顶面施加 u_y = displacement）进行反演实验。实际运行发现严重问题：

> **位移控制下，均匀矩形域的位移场完全由边界条件的运动学约束决定，与材料刚度 E 无关。**

验证实验：分别用 E=50000 和 E=90000 求解相同位移 BC，两者位移场差异 < 1e-17（机器精度）。因此 loss ≈ 0，梯度 ≈ 0，优化器在第一步就"收敛"，实际上根本没有反演。

**根本原因**：平面应变矩形域 + 均匀压缩位移 BC → 应变场 ε = u_y/L_y 是常数，与 E 无关。应力场 σ = E·ε 虽然依赖 E，但我们观测的是位移不是应力。

**解决方案**：改用 **traction loading（Neumann BC）**，在顶面施加均匀面力。此时软区域变形大、硬区域变形小，位移场包含材料信息。

## 1. 本次完成的工作

### 1.1 重写 `common.py`

| 变更项 | 旧版 | 新版 |
|---|---|---|
| 边界条件 | `create_2d_mesh_and_bc(displacement)` — 位移 BC | 新增 `create_2d_mesh_traction_bc(traction)` — 面力 BC |
| Problem 类 | 继承 `Problem`，手写 DP return map | 继承 `DruckerPragerPlasticity2D`，复用 `src/models/` |
| `set_params` | 接受 `(num_cells,)` E 场 | 同左，未变 |
| 参数化 | bounds clipping 或 softplus | **log-E 参数化**：`E = exp(log_E)`，优化在 log 空间进行 |
| Loss 函数 | `displacement_loss(params, fwd, u_obs)` | `make_heterogeneous_loss(fwd, u_obs, obs_indices, reg, λ)` — 返回可微闭包 |
| 正则化接口 | 无 | `smoothness_regularizer(Nx, Ny)` — 结构化网格平滑 |
| Neumann BC | 不支持 | 通过 `_setup_traction()` 动态绑定 `get_surface_maps` |
| 观测生成 | 使用位移 BC | 使用 traction BC |

### 1.2 重写 `h5_two_region.py`

- 改用 traction = -50 MPa（弹性范围内的压缩面力）
- 使用 `scipy.optimize.minimize(method='L-BFGS-B', jac=True)` 在 log-E 空间优化
- bounds: E ∈ [1000, 500000]（log 空间 [6.9, 13.1]）
- 完整的诊断输出：场图、误差图、收敛曲线、中线截面对比

### 1.3 新建 `tests/test_heterogeneous_grad.py`

- 4×4 网格（16 个逐单元参数）
- AD vs FD 逐元素梯度验证：4 个选定元素，相对误差 ~10⁻⁷ ✅
- 方向导数测试：随机方向，相对误差 ~10⁻⁹ ✅

### 1.4 修复 `__init__` 顺序 Bug

**`src/models/drucker_prager.py`** 和 **`src/models/drucker_prager_2d.py`**：

`DruckerPragerPlasticity` 和 `DruckerPragerPlasticity2D` 的 `__init__` 中，`self.E = E` 等赋值在 `super().__init__()` **之后**执行。但 JAX-FEM 的 `Problem` 是 dataclass，`__post_init__()` 在 `super().__init__()` 内部调用 `custom_init()`，而 `custom_init()` 需要 `self.E`。

这意味着直接实例化 `DruckerPragerPlasticity2D(mesh, ...)` 会 **AttributeError**。之前没发现是因为测试文件中的 Problem 子类（如 `DifferentiableDruckerPrager2D`）直接继承 `Problem` 而非 `DruckerPragerPlasticity2D`，硬编码了参数。

**修复**：将材料参数赋值移到 `super().__init__()` 之前。

## 2. H5 实验结果

### 实验设置

| 参数 | 值 |
|---|---|
| 网格 | 20×20 = 400 QUAD4 单元 |
| 域尺寸 | 10×10 m |
| 加载 | 顶面面力 traction = -50 MPa |
| 底面 BC | u_x = 0, u_y = 0（全固定） |
| 真实 E 场 | 左半 50000，右半 90000 MPa |
| 固定 k | 50.0 MPa |
| 初始猜测 | 均匀 E = 70000 |
| 正则化 | 无 (λ = 0) |
| 优化器 | L-BFGS-B (log-E 空间) |

### 结果

| 指标 | 值 |
|---|---|
| 初始 Loss | 1.92e-06 |
| 最终 Loss | 2.65e-09 |
| L2 相对误差 | **16.9%** |
| 左区域平均相对误差 | 11.1% |
| 右区域平均相对误差 | 12.1% |
| E 范围 (反演) | [38672, 148732] |
| 迭代次数 | 16 (124 次函数评估) |
| 耗时 | ~207s (优化) + ~10s (JIT) |
| 收敛状态 | ABNORMAL (梯度振荡) |

### 关键发现

1. **框架闭环验证通过**：AD 梯度正确（10⁻⁷ 精度），traction BC 下位移场确实依赖 E，优化器能显著降低 loss
2. **左右区域可识别**：反演场清楚区分了两个区域
3. **无正则化时伪影严重**：底部边界附近出现极端值（E 从 38672 到 148732），界面过渡平滑
4. **需要正则化**：当前结果的 16.9% L2 误差主要来自边界伪影和界面弥散。这正是阶段 I（正则化）要解决的问题
5. **traction BC vs displacement BC**：traction BC 方案在物理上更合理——对应现场实测的是"已知荷载、观测位移"场景
