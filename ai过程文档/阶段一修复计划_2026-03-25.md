## 任务 1.1：修复 Return Mapping 公式

### 问题本质

当前公式（以 `drucker_prager.py` 第 96-99 行为例）：

```python
n_dev = safe_divide(s_dev, 2. * sqrt_J2_reg)          # ∂f/∂σ 的偏差部分
delta_lambda = f_yield_plus / (1. + 3. * alpha * alpha) # 分母错误
sigma = sigma_trial - delta_lambda * (n_dev + alpha * I) # 修正
```

流动方向 `n_dev = s/(2√(J₂+a²))` 对应 `∂f/∂σ` 的偏差部分。此时偏差修正量为 `Δλ/2`，体积修正量为 `3αΔλ`。代入一致性条件 `f(σ_new) = 0` 求解得：

```
Δλ = f_trial / (1/2 + 3α²)
```

**代码写的是 `1 + 3α²`（分母偏大），导致 Δλ 偏小约 39%。**

### 修复方案

**统一采用弹性模量形式（与 `run_triaxial_final.py` 一致）**，这是计算塑性力学教科书的标准写法：

```python
mu = E / (2. * (1. + nu))
lmbda = E * nu / ((1. + nu) * (1. - 2. * nu))
bulk_K = lmbda + 2./3. * mu

# 正确的 associated DP return mapping
denom = mu + 9. * bulk_K * alpha * alpha
d_lam = f_yield_plus / denom
sigma = sigma_trial - d_lam * (mu * s_dev / sqrt_J2_reg + 3. * bulk_K * alpha * np.eye(dim))
```

数学推导：用 Hooke 定律展开弹性修正 `σ = σ_trial - Δγ C : (∂f/∂σ)`：
- 偏差部分：`s_new = s_trial - 2μ·Δγ·s/(2√(J₂+a²))` → `√J₂_new ≈ √J₂_trial - μ·Δγ/√(J₂+a²)·√J₂`
- 体积部分：`I₁_new = I₁_trial - 9K·α·Δγ`
- 代入 `f(σ_new) = 0`：`Δγ = f_trial / (μ + 9Kα²)`（忽略正则化小量修正）

## 任务 1.2：修复边界条件

### 问题本质

多个文件只约束了底面的 z 方向，x/y 方向完全自由，导致刚度矩阵有刚体平动零特征值。正向求解可能因对称性"侥幸"收敛，但伴随方程（反向 AD）必然失败。

### 修复方案

**最小约束原则**：底面 z=0 + 角点 x=0, y=0（防止刚体平动，不过度约束）。

## 任务 1.3：让测试真正进入塑性

### 问题本质

当前参数 E=70000, k=250, α=0.3 下，单轴压缩屈服应力约：

```
σ_y ≈ k / (1/√3 - α) ≈ 250 / 0.277 ≈ 902 MPa
ε_y ≈ 902 / 70000 ≈ 0.0129 (1.29%)
u_y ≈ 0.129 mm（在 10mm 试件上）
```

测试最大位移 -0.1mm → 应力 ~700 MPa < 902 MPa → **始终在弹性范围**。

### 修复方案

**降低 k 值到 50 MPa**（而不是增大位移，避免大变形问题）：

```
σ_y ≈ 50 / 0.277 ≈ 180 MPa
ε_y ≈ 180 / 70000 ≈ 0.0026 (0.26%)
u_y ≈ 0.026 mm
```

这样位移 -0.1mm 对应应力 ~700 MPa >> 180 MPa，塑性会被充分激活。

## 任务 1.5：改用中心差分

### 问题本质

当前所有 FD 均为前向差分 `(f(x+h) - f(x)) / h`，精度为 O(h)。中心差分 `(f(x+h) - f(x-h)) / (2h)` 精度为 O(h²)，能更可靠地验证 AD 梯度。

### 修复方案

将每个测试中的 FD 计算替换为中心差分。

### 当前代码模板（所有文件大同小异）

```python
# 当前（前向差分）
params_plus = params.at[i].set(params[i] + eps)
loss_plus = loss_fn(params_plus)
grad_fd = (loss_plus - loss_val) / eps
```

### 修复为

```python
# 中心差分
params_plus = params.at[i].set(params[i] + eps)
params_minus = params.at[i].set(params[i] - eps)
loss_plus = loss_fn(params_plus)
loss_minus = loss_fn(params_minus)
grad_fd = (loss_plus - loss_minus) / (2. * eps)
```

### 需修改的文件

7 个文件（排除 `test_diff_elastic.py`，它本身没有 FD 对比）：
- `test_diff_dp.py`（第 127-133 行）
- `test_diff_dp_bc_fix.py`（第 119-121 行）
- `test_diff_dp_hardening.py`（第 113-115 行）
- `test_diff_dp_strategy1_visco.py`（第 117-119 行）
- `test_diff_dp_strategy2_direct.py`（第 104-106 行）
- `test_diff_dp_strategy3_smooth.py`（第 121-123 行）
