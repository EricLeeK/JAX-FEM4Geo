项目总览

自动微分(AD)穿透非线性有限元求解器，实现岩土参数高效梯度反演

核心理念

传统参数反演依赖有限差分(FD)梯度或无梯度优化(PSO)，计算代价随参数维度线性增长。本项目利用 JAX 的自动微分能力，实现 O(1) 梯度计算 — 无论反演 2 个参数还是 2000 个参数，梯度计算时间几乎不变。

群体搜索，无方向信息
25+维度无法收敛
高维完全不可行
AD 梯度 (本项目)

发现的 6 个 Bug 全部已修复

Bug #1 Return Mapping 公式错误

▼

现象：塑性修正量计算不正确，应力-应变曲线与解析解偏离

根因：塑性乘子 Δλ 的分母写错

- delta_lambda = f_trial / (1 + 3 * alpha**2) # 错误
+ delta_lambda = f_trial / (mu + 9 * K * alpha**2) # 正确

1 + 3α² ≈ 1.27 vs μ + 9Kα² ≈ 26923 + 63462 ≈ 90385，差了 7 万倍

已修复 — 使用正确的弹性模量归一化

Bug #2 边界条件缺少角点约束

▼

现象：刚度矩阵奇异，求解器发散或给出异常位移

根因：3D 问题仅约束了底面 z=0，没有约束 x/y 方向的刚体平动和旋转

已修复 — 添加角点 x/y 约束消除刚体模式

Bug #3 屈服强度 k 设置过高

▼

现象：塑性梯度测试"通过"，但实际从未进入塑性

根因：k=250 MPa 远高于试验应力水平 (~100 MPa)，所有积分点始终弹性

- k = 250.0 # 永远不屈服
+ k = 50.0 # 能真正进入塑性
已修复 — k 从 250 降至 50

Bug #4 测试无断言 (assert)

▼

pytest 显示 PASS，但测试函数内部只有 print，没有 assert。8 个测试文件全部添加 assert。

已修复

Bug #5 前向差分代替中心差分

▼
- grad_fd = (f(x+h) - f(x)) / h # O(h) 一阶
+ grad_fd = (f(x+h) - f(x-h)) / (2*h) # O(h²) 二阶
已修复 — 改用中心差分

Bug #6 本构驱动器与 FEM 不同步

▼

驱动器使用了旧版 return mapping 公式，没有跟随 Bug #1 修复同步更新。

已修复 — 同步驱动器代码，验证精度至 1e-13 MPa

Taylor Test：修复前 vs 修复后

Taylor test：AD 梯度正确时 r₁ 应以 O(ε²) 衰减（斜率=2）。修复前斜率=1，说明 AD 梯度完全错误。

位移扫描：误差在弹塑性边界突变

从弹性到塑性，AD/FD 误差从 10⁻¹⁴ 突变至 99%，不是渐变而是跳变。

根因：JIT 闭包捕获 + Tracer 交互

旧代码（有 Bug）

def set_params(self, params):
    self.E_val = params[0]  # Python 属性
    self.k_val = params[1]

def get_tensor_map(self):
    def stress_fn(u_grad, ...):
        E = self.E_val  # 闭包捕获 ← 问题在这
        k = self.k_val
        # JIT 编译时 E,k 被当作常量烙入
        # jax.vjp trace 时产生虚假梯度

修复后代码

def custom_init(self):
    self.internal_vars = [
        ..., E_field, k_field  # 显式 JAX 数组
    ]

def get_tensor_map(self):
    def stress_fn(u_grad, ..., E_arr, k_arr):
        E = E_arr[0]  # 显式函数参数
        k = k_arr[0]  # JAX 可以正确 trace

关键发现：位移 BC 下 E 不可辨识 重要

位移 BC（Dirichlet）

应变 ε = u_y/L 是运动学常数，与 E 无关。Hessian 特征值：-5.46×10⁻⁶（鞍点）。E 梯度 ≈ 0，无法反演。

荷载 BC（Neumann / Traction）

软区域变形大、硬区域变形小，位移场携带 E 信息。Hessian 特征值：正定。可正确反演。

反演框架架构

参数化：log(E) 空间（保证 E > 0）→ 前向求解：FEM Newton-Raphson + PETSc LU 直接求解 → 损失：L = ‖u − u_obs‖² + λ·R(E) → 梯度：jax.grad 通过 ad_wrapper 隐式微分 → 优化：scipy L-BFGS-B

两个独立问题的叠加

问题 A 底部 BC 过度约束

▼

原 BC：整个底边同时约束 u_x=0 和 u_y=0

后果：人为侧向约束 → 剪应力集中 → 触发 DP 屈服 → Newton 振荡（残差在 ~33 和 ~52 间跳动）

- location_fns = [bottom, bottom], vecs = [0, 1]
+ location_fns = [bottom, corner], vecs = [1, 0]
仅约束底边 u_y=0 + 角点(0,0) u_x=0

问题 B 优化中触发塑性

▼

原 k=50：E 变化时部分单元进入塑性 → 非凸景观 → 梯度被污染

- k_fixed = 50.0 # 优化中可能屈服
+ k_fixed = 500.0 # 弹性域策略，Newton 1步收敛
k=500 确保全程弹性（当前目标反演 E 场）

问题现象（v4）

前向求解器始终返回弹性解 → ∂u/∂c=0 → 优化器收到零梯度 → c 不更新 → L2≈50%

根因

残差只要不下降就 diverge_count++，3 次回退。弹塑性过渡区残差自然波动 (0.099→0.105→0.098) 被误判。

Newton: 0.17→best → 0.10 → 0.105 (div+1) → 0.103 (div+2) → 0.101 (div+3, 回退!)

修复方案 (solver.py)

// Newton 散度保护
- if res_val >= best_res_val: diverge++
- max_diverge = 3
+ if res_val > 10 * best_res_val: diverge++
+ max_diverge = 5

softplus 光滑化 (mohr_coulomb_2d.py)

- f_yield_plus = np.where(f > 0, f, 0) # C⁰
+ f_yield_plus = softplus(f, β=100) # C∞

关键教训与已知局限

技术发现

softplus vs np.where：C∞ vs C⁰，直接影响 AD 梯度质量

散度保护阈值至关重要：小幅残差波动 ≠ 发散

正则化权重 λ 差一个量级 = 17% vs 44%

联合 c+φ 反演位移 -0.03 优于 -0.05（深度塑性耦合）

已知局限

c 仅在塑性域有灵敏度 → 弹性区域不可辨识

水平分层 + 竖向压缩 → Newton 发散（层间刚度跳变）

联合反演 c+φ 在深度塑性下非唯一

稀疏观测（40/121 节点）精度受限于信息量

荷载控制 Newton 在大荷载塑性问题上发散（未解决）
