## 2. 阶段 A：核心修复落地

### 任务 A1：`src/models/drucker_prager.py` 迁移到 `internal_vars` 模式

**修改前（BUG）**：

- `custom_init()` 中 `internal_vars = [sigmas_old, epsilons_old]`（只有 2 个）
- `get_tensor_map()` 通过闭包捕获 `self.E`、`self.k`
- 无 `set_params()` 方法
- `update_stress_strain()` 中 `internal_vars` 不包含 E/k

**修改后（FIX）**：

```python
def custom_init(self):
    ...
    E_field = np.full((nc, nq, 1), self.E)
    k_field = np.full((nc, nq, 1), self.k)
    self.internal_vars = [self.sigmas_old, self.epsilons_old, E_field, k_field]

def set_params(self, params):
    nc, nq = len(self.fe.cells), self.fe.num_quads
    self.internal_vars[2] = np.full((nc, nq, 1), params[0])
    self.internal_vars[3] = np.full((nc, nq, 1), params[1])

def get_tensor_map(self):
    ...
    def stress_return_map(u_grad, sigma_old, epsilon_old, E_arr, k_arr):
        E = E_arr[0]
        k = k_arr[0]
        a = a_ratio * k
        ...
    return stress_return_map
```

**关键设计决策**：

| 决策项 | 选择 | 理由 |
|--------|------|------|
| E, k 传参方式 | `internal_vars[2]`, `[3]` | JAX-FEM 官方推荐模式，JIT trace 时可正确追踪梯度 |
| nu, alpha 传参方式 | 闭包捕获 | 不是梯度目标，无需进入 JAX 计算图 |
| a（正则化参数）| 在 kernel 内从 k 计算：`a = a_ratio * k` | a 依赖 k，必须在 trace 内部计算才能正确传播梯度 |
| `self.E`, `self.k` 等实例属性 | 保留 | 向后兼容，`run_fem_simulation.py` 等纯前向脚本直接使用 |

**向后兼容性验证**：

- `examples/run_fem_simulation.py` 使用 `solver()` 直接前向求解 + `update_stress_strain()` —— 构造函数中传入的 `E`, `k` 会通过 `custom_init()` 写入 `internal_vars`，无需任何修改即兼容
- `update_stress_strain()` 已更新为传递 `internal_vars[2]`, `[3]` 给 vmap 调用

### 任务 A2：多步增量加载梯度验证

**新建文件**：`tests/test_diff_dp_multistep.py`

**测试设计**：

```
标准做法：只对最后一步做隐式微分（AD），前序步的历史更新视为固定（stop gradient）
```

两个测试场景：

| 场景 | 位移序列 | 物理含义 | 梯度预期 |
|------|---------|---------|---------|
| `continued_plastic` | [-0.015, -0.030, -0.033] | 弹性→塑性→更深塑性 | E 和 k 梯度均非零 |
| `elastic_unload` | [-0.015, -0.030, -0.020] | 弹性→塑性→弹性卸载 | E 梯度非零，k 梯度为零（卸载时屈服面不活跃） |

**FD 策略**：

与 AD 保持一致——在 nominal params 下重建历史（前 N-1 步），然后仅在最后一步扰动参数，计算中心差分。

**结果**：

| 场景 | rel_err(E) | rel_err(k) | 判定 |
|------|-----------|-----------|------|
| continued_plastic | 4.8e-07 | 1.4e-05 | **PASS** |
| elastic_unload | 5.6e-13 | 0 (正确为零) | **PASS** |
